วิศวกรสร้างตึก หากนึกง่าย

เสาอาจคลาย ฐานอาจพัง ตั้งไม่มั่น

เพียงมักง่าย อาจพรากชีพคนอนันต์

ความประมาทนั้น ย่อมสร้างภัยใหญ่หลวง

---

แพทย์มักง่าย รักษา ไร้ประหวั่น

ผู้ป่วยนั้น อาจทรมาน จนสิ้นหวัง

เพราะความผิด เพียงน้อยนิด อาจปิดบัง

แต่ผลร้ายยัง ฝังลึกเกินเยียวยา

---

อันครูสอน หากมักง่าย ไร้ซึ่งจิต

อนาคต ของศิษย์ อาจเลือนหาย

หนึ่งคำสอน อาจเปลี่ยนชีวิตไปจนตาย

หนึ่งความหมาย อาจกำหนดทั้งชีวิตคน

---

ทุกวิชาชีพ ล้วนมีเกียรติ และหน้าที่

ต้องยึดมี จริยธรรม เป็นเหตุผล

ความรับผิด ชอบตน และผู้คน

คือรากฐาน ค้ำจุนชน ให้พ้นภัย
